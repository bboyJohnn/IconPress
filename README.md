# IconPress

🖼️ Simple image converter and icon maker with macOS-style interface

![Python](https://img.shields.io/badge/Python-3.6+-blue.svg)
![PyQt5](https://img.shields.io/badge/GUI-PyQt5-green.svg)
![Platform](https://img.shields.io/badge/Platform-Windows%20|%20macOS%20|%20Linux-lightgrey.svg)

## Features

- **Format Conversion** - Convert between JPEG, PNG, BMP, ICO, TIFF, WEBP, GIF
- **Icon Creation** - Generate 256×256 `.ico` files from any image
- **Live Preview** - See your image before processing
- **Flexible Output** - Replace original or save to custom folder
- **macOS Style** - Native-looking interface with dark theme support
